# geemu 🐍

A simple, fun browser-based **Snake** game — just open `index.html` in your browser and play!

## How to play

| Key | Action |
|-----|--------|
| `↑` / `W` | Move up |
| `↓` / `S` | Move down |
| `←` / `A` | Move left |
| `→` / `D` | Move right |

- Eat the 🟡 food to grow and earn points.
- Don't hit the walls or yourself!
- Your best score is saved locally in the browser.

## Run

No build step needed — just open `index.html` directly in any modern browser.
